# Remove install banner and notification toggles

## Changes
- Remove the automatic “Install the app” banner from every page.
- Remove notification enable/disable choices from Settings.
- Keep the per-event alert sound selectors and sound previews in Settings.
- Preserve existing saved alert preferences while updating only sound choices.

## Verification
- Confirm the install banner no longer appears on iPhone-sized screens.
- Confirm Settings shows alert sounds without the notification toggle list.
